Before running, the plan is VALIDATED: every step must name a tactic and technique, a target that is in authorised scope, a safety control, a data source and a detection. A step missing any of these is a planning finding and must not be run. The lab's emulation_plan.py performs this validation - it checks each step's fields and confirms the target is within the authorised scope (reusing the scope check from Module 3). A complete, in-scope, safety-bounded, detection-mapped plan PASSES. This makes the plan a safe, reviewable artifact before any activity, and ensures every emulated technique is paired with the detection it is meant to test. The deep dive runs the validation.
