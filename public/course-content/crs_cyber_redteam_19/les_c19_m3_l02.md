Scope enforcement is the control that keeps every action inside the authorised boundary. The rule is FAIL-SAFE: a target is acted on only if it is PROVABLY in scope; anything not provably in scope is treated as out-of-scope and refused. This prevents the single most damaging mistake - touching a system you are not authorised to touch. The lab's scopecheck.py implements this: given the authorised scope and a set of target identifiers, it classifies each as IN-SCOPE (a listed host or an address within an authorised network) or OUT-OF-SCOPE, and refuses to proceed if any is out of scope. Scope enforcement is applied continuously, not once - before every action - because scope is the boundary that authorisation draws.
