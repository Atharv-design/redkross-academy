Sigma status values express maturity: experimental, test and stable (plus deprecated and unsupported). Promote a rule when its false-positive rate is known and acceptable. Record false positives in the rule and turn each one into a negative test. When ATT&CK changes, update tags (Module 7). Deploy content in stages, like code: a staging environment, a canary group, then everyone, with fast rollback. EDR prevention rules and anything that can block or crash endpoints need the most caution. A detection that only alerts can still harm the SOC by flooding the queue, so give new rules a period in "monitor" mode before they page anyone.
