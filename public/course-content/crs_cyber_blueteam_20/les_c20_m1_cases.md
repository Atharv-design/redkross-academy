## Detecting Storm-0558 through an audit log, 2023 Context: in July 2023 CISA and the FBI published advisory AA23-193A, "Enhanced Monitoring to Detect APT Activity Targeting Outlook Online" [C20-M01-R3]. In mid-June 2023 a US federal civilian agency noticed MailItemsAccessed events in its Microsoft 365 audit log with an AppId that did not normally access mailbox items in its environment. It detected the activity because it had enabled enhanced logging of those events and compared them against a baseline of normal Outlook activity. What mattered: the advisory notes that this logging required licensing at the G5/E5 level. Organisations without it lacked the telemetry needed to see the same intrusion. The US Cyber Safety Review Board's later report (dated March 2024, published in April 2024) said that Microsoft learned of the intrusion from the State Department on 16 June 2023. It also described the department's custom alerting rule on MailItemsAccessed. These details come from secondary press coverage of the report and should be checked against the report itself [C20-M01-R4]. Lessons: telemetry availability is a design decision with commercial consequences. One well-chosen data source plus a behavioural baseline beat an advanced adversary. Coverage inventories must include cloud and SaaS audit logs, not just endpoints.



## (FICTIONAL TEACHING SCENARIO): The 79% dashboard This scenario is fictional. Tamarind's SOC dashboard showed 79% ATT&CK coverage, and the board was pleased. During the Module 2 incident, the analyst found that the attacker's scheduled task was visible only because WS-07 happened to be one of four hosts forwarding Security events. A configuration change six months earlier had disabled Windows Event Forwarding on new workstation builds. Nobody noticed, because the dashboard counted rules, not reporting hosts. Lessons: score coverage per host population. Alert on silent sources. Show the denominator.
