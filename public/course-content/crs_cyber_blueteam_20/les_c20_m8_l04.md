A manifest lists each released file with its SHA-256 hash, level and technique tags. It lets anyone verify that the rules running in the SIEM are the ones that passed the gates. It also lets incident reviewers say exactly which version of a rule was live on a given date. Store the manifest and the release report with the release tag in version control. For higher assurance, sign them (Course 12 Module 6 used cosign for build artefacts).
