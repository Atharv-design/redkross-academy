Alerts about one incident arrive with different identifiers: a host name from the endpoint, an IP address from DNS, a user name from identity logs. Entity resolution maps them to the same real entity using an inventory (CMDB), DHCP leases and directory data. Without it, Tamarind's 82 DNS alerts (keyed by 10.20.1.17) and 6 endpoint alerts (keyed by WS-07) become two cases with two analysts, and the DNS case looks like low-severity noise. With it, one case shows 88 alerts from 7 rules - a much clearer picture. Resolution must be time-aware: DHCP addresses move between hosts, so the mapping must hold at the time of the event.
