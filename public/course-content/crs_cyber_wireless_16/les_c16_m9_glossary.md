SSID / BSSID  a Wi-Fi network name / a specific AP's MAC-level identifier. rogue AP  an unauthorised access point on or near the network. evil twin  a rogue AP impersonating a legitimate SSID to lure clients. WPA3 / WPA2  modern Wi-Fi security (SAE / PSK with AES-CCMP). PMF  Protected Management Frames; protects management frames (deauth, etc.). WPS  Wi-Fi Protected Setup; a weak convenience feature to disable. Just Works  a Bluetooth pairing mode with no MITM protection. Secure Connections  Bluetooth pairing using strong (ECDH) key agreement. app sandbox  per-app isolation of files and processes on mobile platforms. keystore  hardware/OS-backed secure storage for cryptographic keys. exported component  an app component other apps can invoke. MASVS / MASTG  OWASP's mobile verification standard / testing guide. insecure data handling  mishandling sensitive data (storage, crypto, transit). static inspection / dynamic testing  reviewing files / observing a running app. BOLA  broken object-level authorisation - reaching another user's object by id. token  a credential (e.g. JWT/OAuth access token) authenticating API requests. enforcing evidence  a control review moving FAIL -> PASS, proving the fix.
