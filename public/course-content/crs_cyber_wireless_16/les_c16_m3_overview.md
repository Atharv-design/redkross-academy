## About this module

Wireless assessment is how a defender checks that a WLAN is actually secure: reviewing configurations against the controls of Module 2, detecting rogue and evil-twin access points, and doing it all within a controlled, authorised and - in this course - offline process. You will analyse a provided site-survey scan with roguescan.py to find impostor access points, and tie it to the configuration review, producing the evidence an audit needs.

## Why it matters

A secure design is only secure if it is deployed and stays that way. Assessment closes the gap between policy and reality: configuration review confirms each AP meets the baseline (WPA3/PMF/WPS/admin/firmware/segmentation), and rogue/evil-twin detection finds the access points that should not be there - an insider's rogue AP bridging the wired network, or an attacker's evil twin harvesting credentials. Both must be done lawfully and without disrupting the network or others, which is why this course assesses from configurations and provided scans rather than by transmitting. Assessment turns "we think it is secure" into evidence.

## Where it is used

WLAN security audits; site surveys and continuous wireless monitoring (wireless intrusion detection); and the periodic review that keeps a wireless estate compliant. It is the assurance half of wireless security.

## Learning objectives

1. Explain the scope and process of a wireless assessment.
2. Perform a configuration review and prioritise findings.
3. Explain rogue vs evil-twin access points.
4. Detect rogue/evil-twin APs from a scan against an inventory.
5. Explain controlled, authorised, non-disruptive assessment.
6. Produce wireless assessment evidence.
