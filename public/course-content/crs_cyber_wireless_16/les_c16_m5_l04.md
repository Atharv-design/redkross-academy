Android apps are built from COMPONENTS - activities (screens), services (background work), broadcast receivers, and content providers (data interfaces). Components can be EXPORTED, meaning other apps can invoke them. Exporting is sometimes necessary (an app that others legitimately launch), but an exported component that performs sensitive actions or exposes data WITHOUT proper authorization is a vulnerability - another app (including a malicious one) can call it. The rule: export only components that must be, and protect exported components with permissions and input validation; an exported content provider that serves app data is especially risky. The lab's demo app exports activities and a content provider without clear need, which mobilecheck.py flags. Component exposure is how an app can breach its own sandbox boundary by invitation.
