## About this module

This module turns the threat model into protection: WPA2 and WPA3, the Personal and Enterprise authentication modes, and the configuration choices of a secure deployment. You will review the lab's Wi-Fi configuration against current guidance with wifireview.py, watching a weak configuration fail every control and a hardened one pass - the defender's core wireless skill.

## Why it matters

The protocol is where wireless security is won or lost. WPA3 with Protected Management Frames and a strong authentication mode defeats eavesdropping, forged management frames and offline password guessing; a misconfiguration - WPA2 with TKIP, a weak passphrase, WPS left on, PMF off, default admin credentials - leaves the network open over the air. Knowing the protections and how to deploy them, and being able to review a configuration against them, is what keeps the air safe. This module is the heart of wireless defence.

## Where it is used

WLAN deployment and hardening; wireless security standards and audits; and the configuration review that confirms an estate meets policy. It is the day-to-day of securing Wi-Fi.

## Learning objectives

1. Explain WPA2 and WPA3 and what each protects.
2. Distinguish Personal (PSK/SAE) and Enterprise (802.1X) modes.
3. Explain Protected Management Frames and why WPA3 requires them.
4. List secure-deployment settings (WPS, firmware, admin, segmentation).
5. Review a Wi-Fi configuration and interpret the findings.
6. Explain passphrase and key strength.

## Before you start
