## About this module

This capstone brings together the whole course: wireless (rogue/evil-twin detection and Wi-Fi hardening), Bluetooth/BLE, mobile apps (static review and insecure data handling), and mobile APIs. You will run the lab's consolidated review, which enforces the Wi-Fi, Bluetooth and API configuration controls (FAIL to PASS) and reports the mobile-app and rogue-AP findings, and you will present the result as evidence - a complete, authorised, offline wireless-and-mobile assessment.

## Why it matters

A real wireless-and-mobile assessment is not a single check - it spans the radio edge (rogue APs, Wi-Fi, Bluetooth) and the mobile system (app and API). The capstone proves you can run the whole assessment, enforce the controls, and present reproducible before/after evidence, all within an authorised, offline, do-no-harm scope. That end-to-end competence - assess, verify, present - is the course's goal and the mark of a wireless-and-mobile security practitioner.

## Where it is used

Wireless and mobile security assessments; secure configuration baselines for Wi-Fi, Bluetooth, apps and APIs; and the evidence that supports audits and release decisions. It is the capstone deliverable of the discipline.

## Learning objectives

1. Integrate wireless, Bluetooth, mobile-app and API security into one assessment.
2. Run the consolidated review and interpret enforcing FAIL-to-PASS evidence.
3. Present assessment findings and remediation clearly.
4. Apply the authorised, offline, do-no-harm scope throughout.
5. Produce a complete wireless-and-mobile assessment deliverable.
