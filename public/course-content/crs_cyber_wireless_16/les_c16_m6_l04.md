Reviewing the demo app with mobilecheck.py puts static inspection into practice. The tool reads the manifest (debuggable, allowBackup, cleartext, exported components, over-requested permissions), the network security config (cleartext permitted, user CAs trusted), and the source excerpt (hardcoded API key, cleartext http endpoint, external-storage token write, token logging, DES/ECB crypto, unsafe WebView settings), and reports each finding with a severity and a MASVS category. The result is a prioritised, categorised findings list - exactly the deliverable of a mobile static assessment. Because the review is a repeatable check over the app's files, its output is reproducible evidence. The deep dive walks the full output; the point is that every finding is a concrete, located, categorised weakness an app owner can fix.
