**A wireless assessment answers:** are our access points configured securely, and are there any access points that should not be there? The process:

1. scope and authorise - define which networks/APs are in scope and confirm written authorisation; radio use and interception are regulated.
2. inventory - know your authorised SSIDs and BSSIDs and your intended configuration baseline.
3. configuration review - check each AP's settings against the baseline (Module 2).
4. rogue/evil-twin detection - compare observed access points (from an authorised site survey) against the inventory.
5. report - prioritised findings, with remediation, and re-test after fixes.

The two technical pillars are configuration review and rogue detection. Both can be done from DATA - a configuration export and a scan capture - without the assessor transmitting anything, which is how this course keeps assessment safe and lawful. The lab provides exactly this data.
