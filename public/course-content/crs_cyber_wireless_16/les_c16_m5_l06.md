The Android security model maps directly onto the OWASP Mobile Application Security Verification Standard (MASVS), the categories used to assess mobile apps (Module 6). The MASVS groups are: MASVS-STORAGE (data storage), MASVS-CRYPTO (cryptography and key handling), MASVS-AUTH (authentication and authorization), MASVS-NETWORK (network communication), MASVS-PLATFORM (platform interaction - components, permissions, WebViews), MASVS-CODE (code quality/build settings), MASVS-RESILIENCE (resistance to reverse engineering/tampering), and MASVS-PRIVACY (privacy) [R2]. The architecture lessons map onto them: storage choices -> MASVS-STORAGE; keys/crypto -> MASVS-CRYPTO; permissions and component exposure and WebViews -> MASVS-PLATFORM; cleartext/TLS -> MASVS-NETWORK; debuggable/backup -> MASVS-CODE/STORAGE. Understanding the model is therefore understanding what the MASVS checks, and the lab's mobilecheck.py reports findings by MASVS category.
