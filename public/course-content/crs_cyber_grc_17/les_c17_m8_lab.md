## Practical 1: Build the integrated register

---------------------------------------------------

**Objective:** Integrate toolkit outputs into one register and one action list.

**Difficulty:** Professional.

**Required tools:** Python 3.10+; spreadsheet; LAB_ASSETS/C17.

**Prerequisites:** Modules 2-7.

**Environment setup:** run all toolkit commands and save the output (for c in risk csf exceptions bia audit vendor; do python grc_toolkit.py $c; done).

**Explicit authorised scope:** fictional data.

**Step-by-step instructions:**

1. Create a register combining the six risks with links to controls, exceptions, audit findings and vendors.
2. Adjust R03's residual for the leaver finding, and justify it.
3. Add risks for the BIA gap (courier API) and the QuickPrint vendor.
4. Produce an action list with owners and dates.

**Expected observations:** at least two new risks; R03 residual raised until remediation; every action linked to a risk.

**Troubleshooting:** avoid duplicate risks, so merge where scenarios overlap.

**Cleanup:** none.

**Learning outcome:** you can integrate GRC information.

## Practical 2: Prepare and role-play a management review

---------------------------------------------------------------

**Objective:** Run a 45-minute mock management review.

**Difficulty:** Professional.

**Required tools:** P1 outputs; slides or document; 4-6 participants.

**Prerequisites:** Lessons L03-L05.

**Environment setup:** roles: CEO (chair), CISO, CIO, CFO, operations head, internal audit.

**Explicit authorised scope:** role-play.

**Step-by-step instructions:**

1. Circulate a 2-page pack: agenda, metrics, top risks, decisions needed.
2. Hold the review. The CISO presents, and the executives challenge.
3. Record decisions, owners and dates in minutes.
4. Debrief: which decisions were clear, and which were deferred and why.

**Expected observations:** decisions on R04, EX-01/EX-02, the leaver remediation funding, the courier API workaround and the QuickPrint vendor.

**Troubleshooting:** if a decision is deferred, record what information is needed and by when.

**Cleanup:** none.

**Learning outcome:** you can drive governance decisions.
