## Practical 1: Build a RACI and escalation path

------------------------------------------------------

**Objective:** Define accountability for key security activities.

**Difficulty:** Professional.

**Required tools:** spreadsheet or text editor.

**Prerequisites:** Lessons L02-L04.

**Environment setup:** none.

**Explicit authorised scope:** fictional organisation (or your own, with approval).

**Step-by-step instructions:**

1. List ten security activities, including incident notification and risk acceptance.
2. Build a RACI with exactly one A per row.
3. Draw the escalation path for a suspected personal-data breach, including CERT-In and DPDP decision points and the time limits.
4. Identify two activities where one person is both doer and checker, and propose independence.

**Expected observations:** business owners are accountable for risk acceptance; legal is consulted or responsible for notifications; internal audit is accountable for independent testing.

**Troubleshooting:** if a row has several As, split the activity.

**Cleanup:** none.

**Learning outcome:** you can make accountability explicit.

## Practical 2: Map a policy hierarchy

--------------------------------------------

**Objective:** Organise documents into policy, standard, procedure and guideline.

**Difficulty:** Professional.

**Required tools:** text editor.

**Prerequisites:** Lesson L05.

**Environment setup:** none.

**Explicit authorised scope:** fictional documents.

**Step-by-step instructions:**

1. Classify these: "Information Security Policy"; "MFA required for remote access"; "Steps to reset a user's MFA"; "Tips for strong passphrases"; "Encryption: AES-256-GCM for data at rest"; "Acceptable Use Policy".
2. For each, assign an approver, owner and review frequency.
3. Write one testable requirement for each standard.

**Expected observations:** policies board-approved and reviewed annually; standards CISO-approved; procedures team-owned.

**Troubleshooting:** if a document mixes levels, split it.

**Cleanup:** none.

**Learning outcome:** you can structure governance documents.
