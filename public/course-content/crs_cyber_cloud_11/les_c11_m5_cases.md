## Storm-0558 and expanded cloud logs, 2023-2026 -------------------------------------------------------------------- Context: CISA's playbook (version 1.0 January 2025, version 1.1 May 2026) states that it was developed following the summer 2023 discovery of a Microsoft Exchange Online compromise. On 15 June 2023 the US Department of State's SOC used an in-house detection tool to flag malicious behaviour later attributed to Storm-0558; the tool relied on enhanced logging capabilities available only to Purview Audit (Premium) customers at that time. Microsoft invalidated the abused key on 24 June 2023 and used MailItemsAccessed events to identify victims. Microsoft then announced it would provide the same set of Purview Audit (Premium) logs to all customers with E3/G3 licences and above [C11-M05-R3]. Visibility lessons: - Detection depends on log availability: know which logs your licences and settings provide, and close gaps before an incident. - Data-access logs (MailItemsAccessed) matter as much as sign-in logs. - Some logs still need manual activation (SearchQueryInitiated). - Customer-side detection found what the provider had not yet seen; customers must monitor their own tenants.
