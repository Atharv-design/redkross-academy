In managed services (EKS, AKS, GKE) the provider operates the control plane - API server, etcd, upgrades of control-plane components - while you remain responsible for RBAC, workloads, network policy, node configuration (unless nodes are also managed), add-ons and the identity integration. Defaults differ between providers and versions, for example API endpoint exposure, audit log availability and encryption options. Practice for every cluster you own: check rather than assume. Read the API server and kubelet flags (or provider settings), test anonymous access, test secret encryption, list admission plugins and policies, and record the results as evidence (Module 8 automates this). The NSA and CISA Kubernetes Hardening Guidance (version 1.2, August 2022) [R5] and the CIS Kubernetes Benchmark provide checklists for these reviews.
