Analysts are human. Common biases in CTI:

| Term | Meaning |
|---|---|
| confirmation bias | seeking evidence for the first hypothesis |
| anchoring | over-weighting the first report (often a vendor headline) |
| availability | over-weighting vivid, recent incidents |
| mirror imaging | assuming the adversary thinks as we would |
| groupthink | converging on the team's or the industry's view |
| attribution bias | the pull towards naming a famous actor (Module 4) |

Structured analytic techniques make reasoning visible and challengeable:

- Key assumptions check: list the assumptions a judgment rests on and ask which, if wrong, would change it.
- Analysis of competing hypotheses (ACH): list hypotheses, score each piece of evidence for consistency with each, and focus on evidence that discriminates.
- Devil's advocacy and red-team review of drafts.
- Indicators and signposts: what would we expect to see if the judgment were wrong?

In the lab, the anonymous paste-site claim (RPT-003) that a named state agency runs MONSOON LANTERN is an anchoring trap: vivid, specific and uncorroborated. Module 2 grades it E5.
