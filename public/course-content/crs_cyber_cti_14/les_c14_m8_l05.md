brief_builder.py automates six checks:

| Term | Meaning |
|---|---|
| B1 | a valid TLP 2.0 label (CLEAR, GREEN, AMBER, AMBER+STRICT, RED) |
| B2 | every judgment has a likelihood term, a confidence level and sources |
| B3 | every cited source exists in the report register |
| B4 | no judgment rests only on E/F-graded or credibility-5+ sources |
| B5 | every recommendation names a valid PIR and an owner |
| B6 | a review-by date |

It also renders confidence as a separate sentence, following ICD 203. Automated checks catch form errors; humans catch substance. Add a peer review (does the evidence support each judgment?), a challenge session for the key judgment (devil's advocacy), and a privacy and legal check (no personal data beyond need, correct TLP).
