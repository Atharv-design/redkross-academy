**Steps:**

1. Collect events from internal telemetry and reports.
2. Model each as a Diamond event with sources and grades.
3. Cluster events using strong links: shared certificates or dedicated infrastructure (Module 3), identical payloads, distinctive behaviour.
4. Build the timeline: here, registration (20-28 September), certificate (28 September), first lures (2-3 October), national CERT advisory (12 October), blocked visit (20 October), confirmed contact (28 October).
5. State competing hypotheses and test them (ACH, Module 1): for example H1 a financially motivated phishing crew; H2 an espionage intrusion set targeting the insurance sector; H3 an access broker preparing access for others.
6. Identify gaps and collection to close them (what tools follow the PowerShell stage? Module 1 SIR-1.2).

The output is a campaign assessment: scope, timeline, behaviour, targets, hypotheses with likelihood and confidence, and recommended defence.
