## Practical 1: Write findings for the web01 case

-------------------------------------------------------

**Objective:** Turn the Module 6 lab evidence into report findings.

**Difficulty:** Advanced.

**Required tools:** text editor; LAB_ASSETS/C09 outputs; evidence_appendix.py.

**Prerequisites:** Lessons L02-L05.

**Environment setup:** run sh rk_c09_net_lab.sh and python timeline.py if you have not already, then python evidence_appendix.py.

**Explicit authorised scope:** lab evidence only.

**Step-by-step instructions:**

1. Produce the evidence appendix and confirm E1's hash matches the capture-time hash in your run's output.
2. Write a five-row evidence timeline with sources.
3. Write three findings using the certainty scale in L04.
4. Write a limitations section with at least four items, including the synthetic nature of the host logs in this lab.
5. Write one alternative explanation and assess it.

**Expected observations:** findings cite E1 and E3. The hash match supports the transfer finding; attribution to a person is "cannot determine".

**Troubleshooting:** if E1 shows MISSING, run the network lab from the LAB_ASSETS/C09 folder.

**Cleanup:** none.

**Learning outcome:** you can write defensible findings.

## Practical 2: Peer review a report

------------------------------------------

**Objective:** Review a colleague's findings (or the poor example in L04) against a checklist.

**Difficulty:** Advanced.

**Required tools:** text editor.

**Prerequisites:** Lesson L06.

**Environment setup:** exchange P1 reports with a peer.

**Explicit authorised scope:** course material.

**Step-by-step instructions:**

1. For each finding, check: evidence cited, reproducible method, consistent certainty language, no person/account confusion, time zone stated.
2. Try to reproduce one finding from the cited item and command.
3. List missing limitations.
4. Write review comments and agree changes with the author.

**Expected observations:** at least one wording change and one added limitation.

**Troubleshooting:** focus on evidence, not style.

**Cleanup:** none.

**Learning outcome:** you can apply technical peer review.
