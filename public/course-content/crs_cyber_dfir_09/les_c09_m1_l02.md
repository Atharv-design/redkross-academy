| Term | Meaning |
|---|---|
| Integrity | do not change original evidence. Work on verified copies. Hash before and after (Module 2). |
| Documentation | record every action, tool and version, time and person, contemporaneously. |
| Repeatability | another competent examiner using your method on the same data should get the same result. |
| Minimal intrusion | where live interaction is unavoidable (memory capture, cloud APIs), choose the least-changing method and record its expected footprint. |
| Competence | work only within your skill. Validate tools before relying on them (the Casey Anthony tool discrepancy, Module 3). |
| Objectivity | seek evidence that could disprove your hypothesis, and report exculpatory findings. |
| Chain of custody | account for evidence possession continuously. |

An often-quoted idea is Locard's exchange principle from traditional forensics: "every contact leaves a trace". Its digital analogue is that activity tends to leave artefacts such as logs, timestamps and cache entries. It must be applied with care. Artefacts can be absent, overwritten or forged, and examiners interact with systems too.
