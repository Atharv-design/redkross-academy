## MOVEit Transfer, 2023 - one injection flaw, many victims ------------------------------------------------------------------------ Context: On 7 June 2023, CISA and the FBI published advisory AA23-158A on the CL0P ransomware gang (also known as TA505). The advisory reported exploitation of CVE-2023-34362, an SQL injection vulnerability in Progress Software's MOVEit Transfer managed file-transfer product, beginning on 27 May 2023 according to open-source information it cited. After exploitation, the actors installed a web shell the advisory names LEMURLOOT and stole data from underlying databases [C12-M03-R1]. Many organisations worldwide that used the product were affected. Lessons for developers: - Injection flaws in widely deployed products have outsized impact, so parameterised data access must be the only allowed pattern, enforced by SAST gates (Module 4). - Defence in depth limits damage when one control fails: least-privilege database accounts, file-integrity monitoring of web directories, and egress restrictions. - Vendors need fast vulnerability response (SSDF RV), and customers need an inventory of products like this to patch quickly (Module 5).



## (FICTIONAL TEACHING SCENARIO): The "admin" flag ---------------------------------------------------------------------- This scenario is fictional. An early version of Tamarind's portal hid the "edit address" button unless the browser's profile JSON said "role":"admin", but the API endpoint itself had no server-side check. An internal tester found that any logged-in user could call the endpoint directly. The fix was a centralised server-side permission check, a negative test for each role, and a review of all endpoints for the same pattern.
