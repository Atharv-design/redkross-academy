```text
Plan and requirements  security requirements (ASVS), data
               classification, privacy requirements (DPDP Act for
               personal data of people in India), abuse cases.
Design         threat modelling (Module 2), secure architecture patterns,
               design review for high-risk features.
Implement      secure coding standards and libraries (Module 3), IDE
               linters, pre-commit secret scanning (Module 6), peer code
               review with security checklists.
Build          SAST (Module 4), dependency and licence scanning (Module
               5), IaC and container scanning, reproducible builds,
               signing (Module 7).
Test           security unit and integration tests, DAST against a test
               deployment, and penetration testing for major releases
               (Courses 05 and 06).
Release        release checklist, artefact verification, SBOM
               publication, change approval, staged rollout.
Operate        monitoring and detection (Course 08), vulnerability
               intake (security.txt, bug bounty), patching, incident
               response (Course 09).
```

Not every feature needs every activity. Scale effort with risk. A marketing page needs less than a payments API.
