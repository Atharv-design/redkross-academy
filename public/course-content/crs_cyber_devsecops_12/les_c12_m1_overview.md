## About this module

A secure software development lifecycle (SDLC) builds security into every stage of how software is planned, designed, written, tested, released and maintained. Security is not a final test before launch. DevSecOps is the practice of doing this at the speed of continuous delivery. Most checks are automated in the pipeline, people focus on design and judgment, and feedback reaches developers within minutes. This module introduces the NIST Secure Software Development Framework (SSDF), shows how to write testable security requirements using OWASP ASVS, maps security activities to each lifecycle stage, and designs security gates that block real risk without stopping delivery.

## Why it matters

A defect is cheapest to fix where it is introduced. A missing requirement found in design costs a conversation. The same gap found after release can cost an incident, a recall or a regulatory penalty. Customers and governments also increasingly ask suppliers to attest to secure development practices.

## Where it is used

Product engineering teams, platform and DevOps teams, application security programmes, vendor assurance and procurement questionnaires.

## Learning objectives

1. Describe the SDLC stages and the security activity at each.
2. Explain the NIST SSDF practice groups and how to use them.
3. Write security requirements that are specific and testable, using OWASP ASVS.
4. Design security gates with clear criteria, owners and exceptions.
5. Measure a secure SDLC programme.
6. Apply staged rollout and release-safety practices.
