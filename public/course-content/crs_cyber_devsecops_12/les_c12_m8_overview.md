## About this module

This final module assembles the course into one working system: a secure release pipeline for the Tamarind shipment service. It runs these gates:

- security unit tests;
- SAST;
- dependency audit;
- secret scanning;
- SBOM and licence inventory;
- signing and verification.

It produces a release security report that a decision-maker can act on. The module teaches how to orchestrate the gates, manage findings through remediation, and write the report. It then sets the course capstone.

## Why it matters

Individual tools only help when they are combined, enforced and reported. Customers, auditors and leadership need to know whether a release is safe to ship, why, and what residual risk remains, in a form they can check.

## Where it is used

Release management, product security sign-off, customer assurance packs (SBOM, attestations), regulated software delivery.

## Learning objectives

1. Orchestrate security gates so every result is captured and the decision is automatic.
2. Keep build tooling separate from what ships, so the SBOM is accurate.
3. Manage findings from detection to verified remediation.
4. Write a release security report with evidence and residual risk.
5. Verify release artefacts against their source and build records.
6. Complete the capstone project.

## Before you start

**Prerequisites:** C12-M01 to C12-M07.

**Estimated study time:** About 8 hours (plus 14 hours capstone).
