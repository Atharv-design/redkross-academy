If a Tier 0 admin must log on only to trusted systems, they need a trusted system to log on FROM. A privileged-access workstation (PAW) is a hardened, dedicated device used ONLY for privileged administration - no email, no web browsing, no general-purpose software - so that it is not exposed to the commodity attacks that compromise ordinary machines. The "clean source" principle generalises this: any system that controls another must be at least as trustworthy as the thing it controls. You cannot securely manage a Tier 0 asset from a Tier 2 machine, because whatever compromises the Tier 2 machine then controls Tier 0. PAWs, jump servers configured as clean sources, and just-in-time administration are the practical implementations.
