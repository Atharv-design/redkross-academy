The configuration review checks the directory against the controls of

**Modules 3-5:** password and lockout policy and PSOs; encryption types (AES, no RC4/DES); delegation; SPNs on user accounts; pre-authentication; dormant and never-expiring accounts; and privileged-group membership. The lab's dir_review.py automates the account-level checks from a read-only LDIF export and returns findings with severity and a fix, and a non-zero exit code when any HIGH finding is present (Module 5). A full review also covers items the lab notes but does not automate: directory ACLs (rights such as DCSync), GPO permissions, trust configuration, and the audit policy itself (Module 6). The reviewer's job is to run the checks, confirm each finding is real (not an expected condition such as DC delegation), and attach evidence.
