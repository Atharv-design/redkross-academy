Every technique above depends on a DIRECTORY CONDITION a defender can find: an SPN on a user account, a disabled pre-auth flag, unconstrained delegation off a DC, a non-expiring or dormant account. The lab's dir_review.py reads a read-only LDIF export of user objects (Module 2's LDAP) and decodes userAccountControl flags and attributes to report these conditions with their severity and fix. It is the same class of check that commercial AD posture tools perform; doing it by hand once teaches what those tools actually look at. Crucially, it reads an EXPORT - it never attacks anything - and it runs against the learner's own domain only.
