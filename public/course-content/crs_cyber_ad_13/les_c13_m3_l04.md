The domain has one default password and lockout policy (historically set in the Default Domain Policy). It controls complexity, minimum length, history, minimum and maximum age, and lockout threshold and duration. For accounts that need DIFFERENT rules - typically service and administrative accounts that need longer passwords - Active Directory provides fine-grained password policies, implemented as Password Settings Objects (PSOs) applied to users or groups with a precedence value. In the lab you will read the domain policy and then create a PSO ("ServiceAccountPSO") that requires a 25+ character password for the service account, with its own precedence, while ordinary users keep the domain default. Long, random secrets for service accounts are one of the two strongest defences against Kerberoasting (Module 5); a PSO is how you enforce them selectively.
