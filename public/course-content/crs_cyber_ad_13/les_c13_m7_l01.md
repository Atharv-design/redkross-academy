Every assessment begins with written authorisation and an agreed scope: which domains and forests, which systems, read-only or change-allowed, what data may be exported, and who is informed. For a directory you administer this is usually straightforward, but it must still be explicit - an export of the directory is sensitive, and an access review touches personal data (names, roles), so handling and retention must be agreed (Course 17; the India law note in Part A). The golden rule of this course applies absolutely: assess only a directory you are authorised to administer. The lab's tools are read-only reviewers of an EXPORT; they are never pointed at anyone else's directory.
