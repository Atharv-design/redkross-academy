Samba emits structured JSON authentication audit events, which the lab captures from the domain controller's output. Each event mirrors the Windows model: it carries an eventId (4624 for a successful authentication), a logonType, a status (NT_STATUS_OK or an error), the client account, the remote address, the service description and - valuably - the passwordType (the Kerberos encryption type). This is why the course can teach real detection without a Windows licence: the same logical events, with the same 4624 identifier and logon types, are available to parse. Where Windows adds events the lab does not (for example the 4769 service-ticket event in its own format), the text says so, and the detections are written against the fields that are present.
