Microsoft's current guidance presents the Enterprise Access Model, which "builds on" the AD tier model and extends it for cloud and modern access [R1]. In it, former Tier 0 expands to become the CONTROL PLANE (everything with control of security-critical assets, on-premises and in the cloud), and former Tier 1 splits into a MANAGEMENT PLANE and a DATA/WORKLOAD PLANE, while former Tier 2 user access splits into USER ACCESS and APP ACCESS. The purpose is unchanged - contain privilege so that control of lower-value assets cannot escalate to control of the enterprise - but it now spans identity systems that are not only on-premises AD (for example Entra ID, cloud management portals, and SaaS admin consoles). For a learner, the key is the continuity: the tier model's discipline (no downward exposure of higher-plane credentials) still holds; the planes just name the assets more precisely for a hybrid world.
