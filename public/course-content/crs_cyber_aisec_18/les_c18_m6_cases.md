## Malicious models on a public hub, February 2024 ---------------------------------------------------------------------- Context: In "Data Scientists Targeted by Malicious Hugging Face ML Models with Silent Backdoor" (27 February 2024), JFrog researchers reported discovering a model "whose loading leads to code execution, after loading a pickle file", and that their analysis had found "around 100 instances of such models to date". The article notes that Hugging Face developed the safetensors format for storing model data safely and runs malware and pickle scanning; JFrog described its own environment scanning new models multiple times daily [C18-M06-R1]. Lessons: - Model files can be executable content; loading untrusted models is running untrusted code. - Prefer safe formats, scan files, and load unknown models only in isolated environments. - Mirror approved models internally and pin digests. - Hub scanning helps but does not replace your own approval process.



## (FICTIONAL TEACHING SCENARIO): The helpful adapter ------------------------------------------------------------------------ This scenario is fictional. A Banyan engineer downloaded a fine-tuned adapter for "better Hindi support" from an unknown publisher and loaded it on a shared GPU server that held cloud credentials. A later scan found the adapter's loader script made an outbound connection. The response: rotate credentials on the server, rebuild it, move model evaluation to an isolated sandbox without credentials or network, and require registry approval for all models and adapters.
