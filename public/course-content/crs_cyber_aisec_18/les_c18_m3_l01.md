| Term | Meaning |
|---|---|
| Direct | the user writes text intended to override the application's instructions (for example asking for the system prompt). |
| Indirect | instructions arrive in content the application retrieves or receives: knowledge-base documents, web pages, e-mails, tickets, file contents, tool results. The user may be an innocent victim (Module 2 trace: the planted page reached an ordinary refund question). |

Typical goals defenders must anticipate: revealing the system prompt or secrets (LLM07), disclosing other users' data (LLM02), causing unwanted tool actions (LLM06), producing harmful or misleading output (LLM09), and inserting links or images that leak data when rendered (LLM05). The probes in this course test these goals with harmless canaries and a simulated tool, so that a "success" proves exposure without harm.
