## About this module

The capstone brings the course together. You will produce a zero trust reference architecture for Tamarind Logistics - the target state, its components and the standards it imposes - and an implementation roadmap that moves the organisation there in phases, with each step validated by the assurance matrix from Module 7. The module teaches how to structure a reference architecture, how to assess current maturity honestly, how to sequence a roadmap by dependency and risk, how to tie every initiative to evidence, and how to present the result to leadership.

## Why it matters

Zero trust is a multi-year programme, not a product. Google's BeyondCorp paper (2014) described removing the requirement for a privileged intranet and moving corporate applications to the internet (case study) - a migration that needed a clear target, staged change and measurement. Organisations that buy components without a reference architecture and roadmap often end up with overlapping tools and the same implicit trust.

## Where it is used

Enterprise security architecture, zero trust programme offices, board and regulator reporting, technology investment cases, merger and cloud migration planning.

## Learning objectives

1. Structure a reference architecture with principles, components, patterns and standards.
2. Assess current maturity against the CISA ZTMM v2.0 pillars and cross-cutting capabilities.
3. Sequence a phased roadmap by dependency, risk reduction and capacity.
4. Link each initiative to an owner and a validating requirement.
5. Check a roadmap automatically for consistency.
6. Present architecture and roadmap to technical and executive audiences.
