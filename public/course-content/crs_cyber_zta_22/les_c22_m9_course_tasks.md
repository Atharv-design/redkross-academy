​## Task C22-CT1 Write a Python script that reads decision_log.jsonl (generated by make_decision_log.py) and prints, for each user, the count of decisions by outcome, distinguishing DENY decisions taken by the fail-closed path from DENY decisions made by the policy engine, and then the number and time range of fail-closed decisions. Explain what the result means for the availability and security of each user's access during the PDP outage.

​## Task C22-CT2 Write a Python script that reads roadmap_fixed.json and requirements.json, reuses control_matrix.py's check function, and prints, for each roadmap phase, how many initiatives are evidenced (their validating requirement is VALIDATED) and the status of each initiative. Explain which initiatives cannot yet be reported as done and what evidence would close them.
