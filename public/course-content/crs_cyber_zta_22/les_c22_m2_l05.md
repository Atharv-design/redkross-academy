**Services also need identities:** cloud instance roles, Kubernetes service accounts federated to cloud IAM, SPIFFE/SPIRE identities for mTLS (Course 15 M06), CI/CD OIDC federation (Course 12 M07). Principles: no long-lived shared secrets; short-lived credentials issued automatically; identity bound to workload attributes (namespace, service account, repository and branch); least-privilege roles per workload; logging of every token use. Static API keys that remain should be stored in a secrets manager, scoped, rotated and inventoried (Course 12 M06).
