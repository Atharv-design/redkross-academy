An INTRUSION DETECTION SYSTEM (IDS) observes traffic and raises an ALERT when it sees something it considers malicious; it does not block. An INTRUSION PREVENTION SYSTEM (IPS) sits in-line and can BLOCK or drop the offending traffic as well as alert. The trade-off: an IPS can stop an attack automatically, but a false positive on an IPS blocks legitimate traffic (an availability risk), so IPS rules must be high-confidence; an IDS is safer to run broadly because a false positive only creates an alert to triage.

**Placement matters:** sensors go at trust boundaries (the perimeter, between internal zones) where they can see the traffic that crosses, and they need visibility (a span port, tap or in-line position) [R1]. In the lab's architecture, the boundaries where an IDS would watch are internet->DMZ, DMZ->app, and any attempt to reach the database.
