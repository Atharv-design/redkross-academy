The capstone (Section 5) is a full authorised assessment of the fictional organisation's network using only the lab assets you own. You review every layer, run each verification tool before and after hardening, analyse the flow telemetry, and produce a consolidated assessment that moves every enforcing control from FAIL to PASS with evidence and documents the residual telemetry signals with containment recommendations. It mirrors a real network assurance engagement end to end - review, harden, verify, report - entirely offline and against systems you own. Completing it demonstrates that you can not only describe network defences but review them, harden them, and prove they work.
