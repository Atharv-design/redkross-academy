Remote access is a prime target, so the VPN/gateway is not enough on its own.

**Controls:** strong, phishing-resistant authentication (certificate- or token-based, with MFA - see Course 06 Module 3); least-privilege access after connection (a connected user reaches only what their role needs, enforced by segmentation and zero-trust access, not flat network access); device posture checks (is the connecting device patched and managed?); session timeouts; logging and monitoring of remote sessions; and prompt de-provisioning when access is no longer needed. Modern Zero-Trust Network Access (ZTNA) replaces the "connect to the network, then you are trusted" VPN model with per-application, continuously-verified access. The theme is the course's: authenticate strongly, grant least privilege, and monitor.
