## About this module

This final module brings the course together into one authorised workflow: take the fictional organisation's network design, firewall policy, segmentation model, TLS configuration and flow telemetry, review each control against defence-in-depth, verify the hardening, and produce a consolidated network security assessment. You will use the lab's tools end to end - firewall.py, segmentation.py, flowcheck.py, tlscheck.py and review.py - and complete a capstone that moves every control from FAIL to PASS and documents the evidence. The emphasis is on the whole: a secure network is not one perfect control but many layers that each do their part and are verified to work.

## Why it matters

Network security is only as strong as its weakest layer, and the only way to know a layer works is to verify it. A design review without verification is an opinion; a verified assessment is evidence. This module teaches the close-out that turns a pile of controls into a defensible network: review each layer, harden it, verify the hardening with a repeatable check, and record the before/after. That evidence is what an auditor, a client or a board actually needs, and producing it is the skill network defenders are paid for.

## Where it is used

Network security assessments and architecture reviews; firewall and segmentation audits; TLS/configuration hardening verification; and the continuous assurance that confirms controls still work after changes. This module mirrors a real network assurance engagement from review to verified hardening.

## Learning objectives

1. Review a network against defence-in-depth across all layers.
2. Verify firewall, segmentation and TLS hardening with repeatable checks.
3. Analyse flow telemetry for residual risk.
4. Produce a consolidated network security assessment with evidence.
5. Move every control from FAIL to PASS and document before/after.
6. Complete an authorised capstone assessment.

## Before you start

**Prerequisites:** Modules 1-7.

**Estimated study time:** About 10 hours (plus the 16-hour capstone).
