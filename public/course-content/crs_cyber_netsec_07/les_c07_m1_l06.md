The lab's Himalaya Retail network is modelled into the six zones above, with a documented set of permitted flows. The architecture makes the crown jewel (the database) reachable only from the application tier on port 5432, and the management plane reachable only over SSH from a controlled zone. Every later module validates one aspect of this model: the firewall policy that implements it (Module 2), the IDS/IPS that inspects boundaries (Module 3), the segmentation matrix that enforces zero-trust flows (Module 4), the TLS on the edge (Module 5), wireless as an additional entry point (Module 6), and the telemetry that detects violations (Module 7). The capstone (Module 8) asks you to design and validate such an architecture end to end.
