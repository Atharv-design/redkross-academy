LATERAL MOVEMENT is how an attacker, having compromised one host, moves to others toward their goal. BLAST RADIUS is how far a single compromise can spread. Segmentation directly limits both: if the user zone cannot reach the database, a compromised workstation cannot pivot straight to the data; if the DMZ cannot reach the database, a compromised web server cannot either. Each boundary the attacker must cross is a chance to stop or detect them. Zero-trust segmentation minimises blast radius by removing default paths entirely. This is why segmentation is the highest-leverage containment control: it does not prevent the initial compromise, but it decides whether that compromise becomes a breach. The lab's forbidden flows (user->db, internet->db, user->mgmt) are precisely the lateral-movement paths segmentation must close.
