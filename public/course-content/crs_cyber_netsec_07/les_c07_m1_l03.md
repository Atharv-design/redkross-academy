DEFENCE IN DEPTH means layering multiple, independent controls so that the failure or bypass of one does not expose the asset. At the network layer this includes: a perimeter firewall; internal segmentation firewalls between zones; an IDS/IPS watching boundaries; host firewalls; strong authentication for remote and management access; and monitoring that can detect what the preventive controls miss. The layers are chosen so an attacker must defeat several, independent mechanisms - and so that monitoring sees them trying. No single layer is assumed perfect. The lab embodies this: a firewall policy, a segmentation matrix, TLS on the edge, and flow monitoring are separate layers, each validated independently.
