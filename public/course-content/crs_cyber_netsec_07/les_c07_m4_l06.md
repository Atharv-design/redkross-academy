The lab makes validation concrete. segmentation.py loads the allowed-flow matrix and a list of connections and reports each as OK or VIOLATION. Of the lab's seven connections, three violate the policy: user->db:5432 (a workstation reaching the database directly), internet->db:5432 (an external host reaching the database - which must never happen), and user->mgmt:22 (a user reaching the management plane). Each is a boundary crossing the architecture forbids and a lateral-movement path an attacker would use. The remediation is to ensure the enforcing controls (firewall/ACLs) actually deny these flows - which, in the firewall module, is exactly what the hardened policy's explicit deny and default-deny achieve. Validation closes the loop between design and enforcement.
