## About this module

Wireless extends the network into the air, where anyone within range can receive the signal - so it needs its own defensive discipline. This module covers Wi-Fi security modes (from the obsolete WEP through WPA2 to WPA3), the risk of rogue and "evil twin" access points, and secure wireless configuration.

**The focus is defensive:** how to choose the right security mode, segment wireless properly, detect rogue access points, and configure a WLAN to resist the common attacks - all without attacking anything. Wireless is a boundary like any other, and it must be designed, configured and monitored accordingly.

## Why it matters

A wireless network is an entry point that bypasses the physical perimeter: an attacker in the car park, not the building, can reach it. Weak Wi-Fi security (legacy WEP/WPA, weak passphrases, default configurations) has led to real breaches, and rogue access points - whether a careless employee's or an attacker's "evil twin" - can bypass controls entirely or harvest credentials. Defending wireless means choosing modern security modes, segmenting wireless from sensitive zones, and detecting rogue devices. Because this is a defender's course, we study how to secure and monitor wireless, not how to attack it.

## Where it is used

Corporate and guest Wi-Fi design and configuration; wireless segmentation; rogue-AP detection and wireless intrusion detection; and WLAN security audits. Guidance follows NIST SP 800-153 for securing WLANs.

## Learning objectives

1. Compare Wi-Fi security modes (WEP, WPA, WPA2, WPA3) and their strength.
2. Explain enterprise versus personal authentication (802.1X vs PSK).
3. Explain rogue and evil-twin access points and the defences.
4. Specify secure wireless configuration and segmentation.
5. Explain how rogue-AP detection works.
6. Apply secure wireless design to the lab organisation.

## Before you start

**Prerequisites:** Modules 1-5 (zones, segmentation, TLS/auth concepts).

**Estimated study time:** About 8 hours.
