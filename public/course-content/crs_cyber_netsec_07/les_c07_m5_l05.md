You do not need to attack a server to assess its TLS - you can REVIEW its configuration: the enabled protocol versions, the offered cipher suites, and the certificate's key size and validity. This offline review finds the weaknesses above without any live scanning. The lab's tlscheck.py does exactly this: it reads a declarative TLS configuration and flags deprecated protocols, weak ciphers, weak keys and expiring certificates, mapping each to the fix. The lab's pre-hardening configuration (TLS 1.0/1.1 enabled, RC4 and 3DES offered, a 1024-bit key, a cert expiring in days) produces five HIGH findings; the hardened configuration (TLS 1.2/1.3 only, AEAD suites, a 2048-bit key, a far-off expiry) produces none. Reviewing configuration is the safe, deterministic way to assess TLS strength.
