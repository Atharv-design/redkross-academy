Network monitoring does not stand alone - it feeds the Security Operations Centre (Course 08), where network telemetry is correlated with endpoint and identity data in a SIEM, triaged, and escalated into incident response. A network signal (a beacon, a scan, a policy violation) becomes an alert, which an analyst enriches (what host, what asset, what user), validates, and - if real - escalates to containment and response. Threat hunting (Course 20) proactively searches the same telemetry for patterns no rule caught. The network defender's monitoring is thus the front line of a larger operation: good telemetry, tuned detection, and the ability to contain quickly are what make the whole defence responsive. The lab's flow analysis is the kind of signal that enters this pipeline.
