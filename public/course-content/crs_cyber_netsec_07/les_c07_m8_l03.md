Secure connectivity (Module 5) is verified by reviewing the TLS configuration against current standards: no deprecated protocols (TLS 1.0/1.1 are deprecated by RFC 8996), no weak ciphers (RC4, 3DES), RSA keys at least 2048 bits, and unexpired certificates. tlscheck.py performs exactly this offline review. The lab's pre-hardening config returns five HIGH and one MEDIUM finding (old protocols, weak ciphers, a short key, a near-expiry certificate); the hardened config - TLS 1.2+ only, strong ciphers, 2048-bit+ keys, valid certificate - returns zero. As with the firewall, verification is the same check run twice, with the evidence being the finding count going to zero.
