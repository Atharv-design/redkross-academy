Transport Layer Security (TLS) protects application traffic (most visibly HTTPS) by providing CONFIDENTIALITY (encryption), INTEGRITY (tamper detection) and AUTHENTICATION (the server proves its identity via a certificate; optionally the client too). A TLS connection is established by a handshake that authenticates the server and negotiates keys. The current version is TLS 1.3 (defined in RFC 8446), which is faster and drops legacy weak options; TLS 1.2 remains acceptable, while TLS 1.0 and 1.1 are formally deprecated (RFC 8996) and must be disabled [R1][R2]. TLS is the workhorse of secure connectivity on the modern internet, and its strength depends entirely on configuration - versions, cipher suites and certificates.
