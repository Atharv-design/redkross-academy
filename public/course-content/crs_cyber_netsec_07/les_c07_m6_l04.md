A ROGUE access point is an unauthorised AP connected to the network - often an employee plugging in a consumer router for convenience, which can bypass the organisation's wireless security entirely and create an unmonitored entry point. An EVIL TWIN is a malicious AP that impersonates a legitimate network (same SSID) to trick users into connecting to it, so the attacker can intercept traffic or harvest credentials. Both subvert the perimeter: the rogue AP opens an uncontrolled door; the evil twin lures users outside the real controls.

**Defences:** detect unauthorised APs (rogue-AP detection, below); use Enterprise authentication with server-certificate validation so clients will not trust an impersonator; educate users; and physically and logically control what can connect to the wired network. This is covered defensively - the point is to detect and prevent, not to operate such a device.
