**Common indicators:** file hashes (MD5, SHA-1, SHA-256), IP addresses, domain names, URLs, email addresses and subjects, registry keys, file paths, mutex names, user-agent strings, certificate fingerprints, JA3/JA4-style TLS fingerprints. David Bianco's "Pyramid of Pain" (2013) ranks indicator types by how much pain denying them causes the adversary, from bottom to top: hash values, IP addresses, domain names, network and host artifacts, tools, and tactics, techniques and procedures (TTPs) [R1]. Hashes are trivial for an attacker to change (recompile or alter one byte); TTPs are expensive to change. Detections should therefore climb the pyramid: in this course, rule R1 (Office spawning a shell) detects a behaviour, which survives a change of domain or file; the IOC feed below detects specific infrastructure, which will change.
