| Term | Meaning |
|---|---|
| Firewall logs | allowed/denied connections (5-tuple). |
| Proxy / secure | URLs, users, bytes, categories - the dataset's largest |
| web gateway logs | source (284 events). |
| DNS logs | queries and answers - reveal domains even for encrypted traffic. |
| Flow records | NetFlow/IPFIX: who talked to whom, how much, how long. |
| IDS/NDR alerts | signature and anomaly detections (Course 07). |

Encryption hides content but not metadata: destinations, timing, volumes and TLS server names still support detection (for example the dataset's regular 220-byte connections every five minutes).
