## About this module

Telemetry is the data systems emit about what they are doing. A SOC can only detect what its telemetry records. This module surveys the three telemetry families SOCs rely on - endpoint, network and identity - and what each reveals; teaches the anatomy of events (fields, identifiers, timestamps and time zones); and explains how collection pipelines move data from sources to the SIEM reliably and lawfully. Using the course dataset you will build a first timeline of the day at Banyan Microfinance.

## Why it matters

Gaps in telemetry are gaps in defence: Equifax's monitoring device stopped inspecting encrypted traffic for about ten months because of an expired certificate (case study). Timestamp errors make timelines wrong. And Indian covered entities must retain ICT logs for 180 days within India.

## Where it is used

Log source onboarding, SIEM architecture, EDR deployment, network sensor placement, audit evidence.

## Learning objectives

1. Describe endpoint, network and identity telemetry and what each shows.
2. Identify key event fields for common sources.
3. Normalise timestamps to UTC and explain time-zone and clock risks.
4. Design a collection pipeline with reliability and integrity.
5. Assess telemetry coverage against threats.
6. Build a basic multi-source timeline.
