Confirming access-control flaws needs only the minimum safe check: can a user reach something they should not? For IDOR, log in as one user and request another user's object id; if it returns, ownership is not enforced. For the function-level gap, request the privileged page with only a forged role cookie; if it returns, the server trusts the client. Both checks are read-only proofs on an owned target - no data is altered, nothing external is touched. findings.py performs exactly these two checks, and report.py ranks them 8.2 (broken /admin) and 6.5 (IDOR) by CVSS. The deep dive shows the proofs.
