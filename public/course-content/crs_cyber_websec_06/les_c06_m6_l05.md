Path traversal (CWE-22) occurs when user input is used to build a file path without ensuring the result stays inside an intended directory, so input like ../../etc/passwd (or ../app.py in the lab) escapes to files outside the intended folder. Impact: reading arbitrary files (configuration, secrets, source) and, with uploads, writing dangerous files. Safe file handling: canonicalise the resolved path (os.path.realpath) and confirm it is within an allowed base directory before opening it; reject inputs containing path separators or "..", or better, do not use user input as a path at all - map an identifier to a known file server-side. For uploads, validate type and size, store outside the web root, and never trust the client-supplied filename. In the lab, /download joins input to a base without canonicalisation, so ../app.py escapes it; the hardened app resolves the path and confirms it stays within the base.
