Account recovery ("forgot password") is authentication's back door and is frequently the weakest link: if recovery is weak, the password and even MFA can be bypassed. Classic flaws: predictable or long-lived reset tokens; security questions with guessable answers; sending a new password in plain email; or a reset flow that does not invalidate existing sessions. Safe recovery: generate a high-entropy, single-use, short-lived reset token; send a link (not a password) over a verified channel; require the token plus proof of control of the account's contact; invalidate the token on use and expiry; rotate the session and, ideally, re-verify MFA; and notify the user of the reset. Treat the recovery path with the same rigour as login - attackers certainly do.
