Access control decides whether a subject (user) may perform an action on an object (resource). Common models: Role-Based Access Control (RBAC), where permissions attach to roles (customer, admin) and users get roles; and Attribute-Based Access Control (ABAC), where decisions use attributes of the user, object and context (for example "owner of this record", "during business hours"). The guiding principle is LEAST PRIVILEGE: each user and component gets only the permissions needed, nothing more. Two kinds of check matter: OBJECT-level ("may this user access THIS record?") and FUNCTION-level ("may this user call THIS function/endpoint at all?"). Most web authorisation flaws are a missing object-level or function-level check.
