The ATTACK SURFACE of a web application is the set of all points where an attacker can supply input or trigger behaviour: every URL, every parameter (query string, form field, header, cookie, JSON field), every file upload, every API endpoint, and every externally influenced value. A TRUST BOUNDARY is a line input crosses from untrusted to trusted - from the browser into the server's code, or from one service into another. Weaknesses live where untrusted input crosses a trust boundary without being validated, encoded or authorised. Mapping is the act of enumerating the attack surface and marking the trust boundaries, so you know every place input enters and what it reaches (a database, the file system, an outbound request, the HTML output).
