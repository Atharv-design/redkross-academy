HTTP (Hypertext Transfer Protocol), specified in RFC 9110 for its semantics, is a request-response protocol [R1]. A request has a method and target (for example GET /search?q=ghats), a set of headers (Host, Cookie, User-Agent, Content-Type), and an optional body (used by POST and PUT). A response has a status line (for example HTTP/1.1 200 OK), headers (Content- Type, Set-Cookie, Content-Length, security headers), and a body (the HTML, JSON or file). HTTP is text-structured and inspectable: you can read exactly what the client sent and the server returned, which is why web testing is so tractable. In the lab, a request to GET /login?user=asha&pw=reader123 returns a 200 response that sets a session cookie - every element of which you can observe and reason about.
