XXE (CWE-611) occurs when an application parses XML with a parser that processes external entities, and an attacker supplies XML that defines an entity pointing at a local file or a URL. When the parser resolves the entity, it can read local files (disclosing configuration or secrets), make outbound requests (SSRF), or cause denial of service (entity expansion). The root cause is a dangerous parser default - resolving external entities - combined with parsing untrusted XML. The fix is simple and definitive: configure the XML parser to DISABLE external entity and DTD processing (every major parser supports this), and prefer less complex formats (JSON) where possible. XXE maps under OWASP A05:2025 Injection in the current list (historically its own category) [R1][R2]. Never parse untrusted XML with external entities enabled.
