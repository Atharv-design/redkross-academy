Function-level access control governs whether a user may invoke a privileged FUNCTION or reach a privileged PAGE at all - independent of any specific object. The flaw: a privileged endpoint (an admin page, a delete action) relies on the UI hiding it, or trusts a client-supplied value, instead of checking the authenticated user's role on the server. If /admin is reachable by anyone who knows the URL, or by setting a cookie like role=admin, the function-level control is broken. In the lab, /admin trusts a forgeable role cookie (and does not require a real admin session), so findings.py reaches the admin user list by sending Cookie: role=admin - a broken function-level check scoring CVSS 8.2.
