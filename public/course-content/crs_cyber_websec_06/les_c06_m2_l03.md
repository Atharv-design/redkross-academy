Endpoint discovery is enumerating what the application exposes. Legitimate, authorised sources include: the application's own links and forms; its sitemap and robots.txt; API documentation; the source code (for your own app); and observed traffic. Discovery must stay strictly within the authorised scope - the owned, loopback-only target. The lab's map.py probes a KNOWN list of endpoints on 127.0.0.1 and refuses any other host in code; it does not attack third-party systems, and neither must you. Note what robots.txt reveals: the lab's lists /admin, /download and /fetch as "disallow" - which, far from hiding them, advertises sensitive paths to anyone who reads the file (a common real-world information leak).
