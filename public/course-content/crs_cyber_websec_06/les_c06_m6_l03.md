SSRF (CWE-918) occurs when the server makes an outbound request to a URL influenced by user input, letting an attacker choose the destination. The danger is that the SERVER can often reach places the attacker cannot: internal services (databases, admin panels), link-local cloud metadata endpoints (which can expose credentials), and other hosts behind the firewall. An attacker who controls the URL a server fetches can probe and reach these internal targets through the server. SSRF is a common and serious weakness, and in the OWASP Top 10:2025 it is mapped under A01 Broken Access Control (as CWE-918) rather than a standalone category [R1]. In the lab, /fetch?url= fetches any URL the caller supplies; the proof (below) stays entirely on loopback.
