The course's workflow, aligned to the OWASP Web Security Testing Guide and the NIST SP 800-115 phases from Course 05, runs: authorise and scope; map the application; classify entry points; verify each weakness with the minimum safe check; score with CVSS and record evidence; report with remediation; and remediate and retest [R1]. The lab tools implement every step: scope.md (authorise), map.py (map/classify), findings.py (verify), cvss.py (score), report.py (report), and retest.py plus app_fixed.py (remediate and retest). Running them in order produces a complete, evidenced assessment of the owned target - the model for the capstone.
