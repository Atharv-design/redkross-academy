Part 1 — Hook

In biology, a virus is not an animal. It is not a plant. It is a tiny, mindless package of genetic code that cannot live on its own. It enters a living cell, hijacks the cell’s machinery, forces the cell to make thousands of copies of itself, and eventually destroys the cell in the process.

In computing, malware works the exact same way. The word “malware” is short for malicious software. It is an umbrella term for any program or file that is created to harm, exploit, steal, or compromise a computer system, network, or user. Just as there are different kinds of biological pathogens — bacteria, viruses, fungi, parasites — there are different families of malware. Each family has a different structure, a different way of spreading, a different target, and a different way of causing damage.

If you are a doctor, you do not treat a bacterial infection with an antiviral drug. You need to know what you are fighting. If you are a cybersecurity defender, you do not fight ransomware the same way you fight spyware. You need to know which family of malware you are dealing with, how it entered the system, what it is trying to achieve, and how to eradicate it.

This lesson is your guide to the malware families. By the end of this lesson, you will be able to look at an incident report, identify the malware family, and understand the exact mechanism it uses to break your systems.

Part 4 — Concept from Scratch

Here is the central sentence of this lesson.

Malware is not a single tool; it is a diverse ecosystem of malicious software, where each family has evolved a specific strategy for entering a system, hiding from defenders, executing its payload, and achieving the attacker’s objective.

Let me say that again, because it is the distinction that separates beginners from professionals.

Malware is a diverse ecosystem where each family has a specific strategy for entering, hiding, executing, and achieving its objective.

Before we look at the families, let us be very clear about what malware is not.

A vulnerability is a weakness in software (like a door left unlocked).
An exploit is the code or technique used to take advantage of that vulnerability (like picking the lock).
Malware is what the attacker brings through the door once it is open (like the stolen goods they carry out).

An attacker might use a zero-day exploit to gain access, but once inside, they drop a piece of ransomware to encrypt the files. The exploit opened the door; the malware did the damage.

Part 5 — How It Works: The Major Malware Families

Let us walk through the major malware families one by one, examining how they work, how they spread, and what they cost the victim.

1. Viruses and Worms — The Replicators

We touched on these briefly in our history lesson (Module 1 Lesson 2) when discussing the Morris Worm and the Melissa virus. Now let us look at their mechanics.

Viruses: A virus is a piece of malicious code that attaches itself to a legitimate host program or file. It cannot run on its own; it requires a user or a system process to execute the host file. Once the host runs, the virus code executes first, copies itself into other files on the system, and then allows the host program to run normally (or crashes it). Viruses spread through file sharing, USB drives, email attachments, and downloads.

Worms: A worm is completely self-contained. Unlike a virus, it does not need a host file, and it does not need a user to open anything. A worm is designed to scan the network, find vulnerabilities in other computers, exploit them automatically, copy itself to the new machine, and repeat the process. Because they do not need human interaction, worms can spread across the entire globe in minutes, exactly as SQL Slammer did in 2003.

The core difference: A virus needs a host and a human to move. A worm is a self-driving vehicle that moves across the network on its own.

2. Trojans — The Deceivers

A Trojan (short for Trojan Horse) is malware that disguises itself as legitimate, desirable, or harmless software in order to trick the user into installing it.

Think of a game downloaded from an unofficial website that looks like fun, but in the background, it installs a hidden backdoor that gives an attacker full remote control of your computer. Or think of a PDF attachment named invoice_approved.pdf.exe that looks like a document but is actually an executable program.

How Trojans work: They rely entirely on social engineering (tricking humans). They do not replicate themselves like worms or viruses; each victim must be tricked individually. Once installed, however, a Trojan often drops other malware — downloading ransomware, spyware, or cryptominers onto the machine.

Backdoors: Many Trojans install a backdoor — a hidden entry point that bypasses normal authentication mechanisms. Once a backdoor is installed, the attacker can log into the machine anytime they want, download more tools, steal data, or use the machine as a pivot point to attack other computers on the internal network.

3. Ransomware — The Extortionists

Ransomware is currently the most commercially successful and disruptive malware family on earth. It locks a user’s or an organization’s files by encrypting them with strong cryptography, rendering them completely unreadable. The attacker then leaves a digital ransom note demanding payment (usually in cryptocurrency like Bitcoin) in exchange for the decryption key.

There are two primary types of ransomware:

Locker ransomware: Locks the user out of the operating system entirely, displaying a full-screen image that prevents interaction with the desktop or apps. The underlying files are usually not encrypted, but the system is unusable.
Crypto ransomware: Leaves the operating system running, but silently encrypts all valuable files (documents, databases, photos, spreadsheets) using advanced algorithms like AES-256 or RSA-2048.

The modern evolution — Double Extortion: Early ransomware only encrypted files. If an organization had good backups, they could simply wipe the infected machines, restore from backup, and tell the hackers to get lost. Modern cyber criminal groups changed the game: before encrypting the network, they exfiltrate (steal) gigabytes of sensitive corporate data. If the victim refuses to pay the ransom for the decryption key, the criminals threaten to publish the stolen confidential data publicly on a leak site. This forces organizations to pay even if their backups are pristine.

4. Spyware and Keyloggers — The Silent Observers

Spyware is software designed to gather information about a person or organization without their knowledge and send it to a third party.

Keyloggers: A specific type of spyware that records every keystroke made on a keyboard. Every password you type, every chat message you send, every bank account number you enter is logged and transmitted back to the attacker.

Adware: A milder form of spyware that tracks your browsing habits and populates your screen with targeted advertisements. While adware is often treated as a nuisance rather than a critical threat, it frequently installs tracking cookies and redirects web traffic, degrading system security.

Commercial Spyware: Highly sophisticated spyware (such as Pegasus) sold to governments and law enforcement agencies. These tools can turn on a phone’s microphone and camera remotely, read encrypted messaging apps, and extract all location data without the owner ever knowing.

5. Rootkits and Bootkits — The Deep Concealers

A rootkit is a collection of software tools designed to enable unauthorized access to a computer while actively hiding its presence from the operating system and from security tools like antivirus.

How rootkits hide: A normal program asks the operating system (Windows or Linux) for a list of running processes or files on the hard drive. A rootkit compromises the operating system kernel itself (the core engine of the OS). When antivirus asks the kernel for a list of files, the rootkit intercepts the request and edits the response, making the malicious files invisible. You can look right at the malware file on your hard drive, but the OS tells you it is not there.

Bootkits: A specialized form of rootkit that infects the Master Boot Record (MBR) or the UEFI/BIOS of a computer. This means the malware loads before the operating system even starts up. By the time Windows or Linux boots, the malware is already running at the highest privilege level, controlling the hardware. Bootkits are exceptionally difficult to detect and often require wiping the hardware entirely.

6. Fileless Malware — The Ghosts in Memory

Traditional malware is a file stored on a hard drive (like malware.exe). Antivirus software scans hard drives looking for known files.

Fileless malware changed the rules. It writes nothing to the hard drive. Instead, it injects its malicious code directly into the computer’s volatile memory (RAM) or abuses legitimate administrative tools that are already built into the operating system (such as PowerShell, WMI, or macros in Microsoft Office).

Why it works: Because there is no file on the disk, traditional file-scanning antivirus cannot find it. When the computer restarts, the RAM is cleared, but the malware often uses a persistence mechanism (like a scheduled task or a registry entry) to run a tiny script upon boot that downloads the fileless payload straight back into RAM. It is living off the land — using the operating system’s own tools against it.

Part 6 — How Malware Evolves and Evades Detection

Attackers know that antivirus companies write signatures (digital fingerprints) for known malware. If a file’s hash matches a known bad signature, antivirus blocks it. To defeat this, malware authors use advanced evasion techniques.

Polymorphic Malware: Malware that changes its outward appearance (its binary code) every time it replicates or infects a new system. It uses a mutation engine to encrypt or encode its body differently each time, so its digital signature changes constantly, evading simple signature-based scanners.

Metamorphic Malware: Even more sophisticated than polymorphism. Metamorphic malware does not just encrypt itself; it completely rewrites its own internal structure and instructions every time it spreads. It changes variable names, reorders routines, and adds garbage code, making it look like a completely different program while performing the exact same malicious function.

Obfuscation and Packing: Attackers take their malicious code and run it through “packers” — tools that compress and encrypt the executable. When the packed malware runs, a small unpacker stub decrypts the real payload directly into memory. To a basic scanner, the file looks like a compressed archive; once running, it turns into malware.

Part 7 — Attack and Defence View

Let us look at malware from both sides of the coin.

The Attacker’s Strategy:
The attacker’s goal is not just writing malware; it is delivering it and keeping it alive. The attack follows the kill chain we studied in Module 1:

Delivery: Phishing email, malicious website, infected USB, or compromised software update (Supply Chain).
Execution: Tricking the user into opening it, or exploiting a vulnerability to run it automatically.
Persistence: Creating a registry key, a scheduled task, a startup service, or a bootkit so the malware survives a reboot.
Privilege Escalation: Exploiting local system weaknesses to gain Administrator or Root rights.
Defense Evasion: Disabling antivirus, clearing event logs, using rootkits or fileless techniques.

The Defender’s Strategy:
Defenders cannot rely on a single wall to stop malware. This is where Defence in Depth (Module 2 Lesson 4) becomes essential:

At the Email Gateway: Block known malicious attachments and phishing links before they reach the user’s inbox.
At the Endpoint (EDR): Instead of just looking for known file signatures (antivirus), Endpoint Detection and Response (EDR) tools monitor behavior. If a normal Microsoft Word document suddenly starts spawning a command-line terminal and downloading an external file, EDR flags it as suspicious behavior and kills the process immediately, regardless of whether the file is known or fileless.
In the Network: Monitor DNS traffic and outbound connections. If an infected machine tries to “phone home” to a known command-and-control (C2) server, network firewalls and intrusion detection systems block the traffic.
With Backups: Keep offline, immutable backups so that if ransomware strikes, you can restore clean data without paying the extortionists.
Part 8 — Common Mistakes Beginners Mistakes

Mistake 1: Believing that a good antivirus makes you 100% safe. Antivirus is necessary, but it is only one layer. Modern fileless malware, zero-day exploits, and sophisticated phishing bypass traditional antivirus routinely. Security requires EDR, patching, user training, and network segmentation.

Mistake 2: Assuming malware always makes a computer slow or crash. The most dangerous malware is the quietest. Spyware, data-exfiltration trojans, and persistent backdoors are designed to run silently in the background for months or years. A slow computer is annoying; a silent spy in your network is catastrophic.

Mistake 3: Thinking Macs or mobile phones cannot get malware. While Windows is heavily targeted due to market share, macOS, Linux, Android, and iOS all have malware families designed specifically for them. No operating system is magically immune to bad code or social engineering.

Mistake 4: Believing that paying a ransomware ransom guarantees you get your files back. Criminals are criminals. Once you pay, they have your money and no incentive to help you. Many victims who pay never receive the decryption key, or receive a key that only decrypts half their files. Backups are the only reliable guarantee.

Part 9 — Guided Mini-Lab: Investigating File Hashes and Signatures

Let us do a practical exercise in understanding how security tools identify malware. This takes 15 minutes.

Step 1: Understand what a hash is.
A cryptographic hash (like SHA-256) is a mathematical fingerprint of a file. If you change even a single comma in a file, its hash changes completely. Antivirus and security analysts use hashes to identify known malware instantly without having to read the whole file.

Step 2: Check your own system processes (Conceptual or real).
Open your terminal (or Task Manager / Activity Monitor on your computer):

On Windows Task Manager: look at the running processes. Are there any strange names you don’t recognize?
On Linux/Mac terminal, type:
bash
  ps aux | head -20

This lists the active processes running on your machine.

Step 3: Understand VirusTotal.
Security professionals use a free online tool called VirusTotal (virustotal.com). If you find a suspicious file on your computer, you do not open it to test it. You calculate its cryptographic hash and look up that hash on VirusTotal.

Step 4: Write a simple Python script to calculate a file’s hash.
Open VS Code, create a file called hasher.py, and paste this simple script:

python
import hashlib
import sys

def get_file_hash(filepath):
    sha256_hash = hashlib.sha256()
    try:
        with open(filepath, "rb") as f:
            for byte_block in iter(lambda: f.read(4096), b""):
                sha256_hash.update(byte_block)
        return sha256_hash.hexdigest()
    except Exception as e:
        return str(e)

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Usage: python3 hasher.py <path_to_file>")
    else:
        file_path = sys.argv[1]
        print(f"Calculating SHA-256 for: {file_path}")
        file_hash = get_file_hash(file_path)
        print(f"Hash: {file_hash}")

Step 5: Run it on a safe text file.
Create a test file test.txt with the words “Hello Security” and run your script on it. You have just created a tool that generates the exact same digital fingerprinting mechanism used by professional security analysts worldwide.

Part 11 — Summary and Glossary

Here is what we covered.

Malware is malicious software created to compromise systems. It differs from vulnerabilities and exploits: vulnerabilities are weaknesses, exploits open the door, and malware is the damage brought inside.

The major families are viruses (need a host file), worms (self-replicating across networks), Trojans (disguised as useful software), ransomware (encrypts files for extortion), spyware/keyloggers (steals data silently), rootkits/bootkits (hides at the OS or kernel level), and fileless malware (runs entirely in RAM without touching the disk).

Attackers use advanced evasion techniques like polymorphic and metamorphic code to change their appearance and defeat basic signature-based antivirus. Defenders respond with Defence in Depth, combining email gateways, EDR behavioral monitoring, network firewalls, and immutable backups.

Glossary of 10 terms:

Malware — malicious software created to harm or exploit systems.
Virus — malware that attaches to a host file and spreads when the file runs.
Worm — self-replicating malware that spreads across networks without human interaction.
Trojan — malware disguised as legitimate software to trick users.
Ransomware — malware that encrypts files and demands payment for the key.
Spyware — software that secretly gathers user information.
Rootkit — malware that hides its presence by compromising the OS kernel.
Fileless malware — malware that runs entirely in RAM and leaves no files on the disk.
Polymorphic code — malware that changes its binary signature every time it replicates.
Cryptographic hash — a unique digital fingerprint of a file used for identification.
